# Listik: Electron и темы Omarchy

Статус: согласован пользователем 2026-11-05; реализован и проверен по одноимённому плану.

## Согласованные решения

- Устанавливаемое приложение — Electron с Chromium, открывающий существующий сайт Listik.
- Веб-интерфейс доставляется прежним способом при загрузке сайта. Новая сборка не должна принудительно перезагружать открытый редактор.
- Оболочка и движок обновляются отдельно, через пакет приложения.
- В новой установке данные получает существующая синхронизация с сервером. Перенос профиля PWA не нужен.
- В Omarchy приложение всегда следует его теме. Ручного выбора встроенной темы в этом режиме нет.
- Обычная веб-версия и PWA сохраняют нынешнее поведение тем.

## Рассмотренные подходы

1. Electron открывает сайт: сохраняет доставку веб-обновлений и объединяет окно и доступ к палитре. Выбран пользователем; требует регулярных обновлений Chromium вместе с Electron.
2. Веб-сборка внутри пакета: связывает обновление интерфейса с обновлением пакета. Не выбрано.
3. Системный Chromium и локальный посредник: экономит отдельный движок, но требует отдельного канала связи и управления посредником. Не выбрано.

## Предлагаемое поведение

Оболочка читает активную палитру Omarchy при запуске и отслеживает её замену. При смене палитры интерфейс обновляет цвета без перезапуска, потери фокуса или изменения документов. Светлый/тёмный режим берётся из темы, а не из прежнего выбора Listik.

При активной интеграции пункт ручной смены темы скрыт; команда смены темы также недоступна. Прежние настройки браузера не перекрывают палитру Omarchy. Выбор оформления не синхронизируется между устройствами.

Сохраняются размеры, расположение элементов и системные шрифты Listik. Меняются все смысловые цветовые токены: фон, поверхности, текст, акцент, ссылки, теги, форматирование, выделение, поиск и ошибки. Производные оттенки рассчитываются из палитры с проверкой читаемости. Поддержка не зависит от названия темы.

Если файл временно недоступен во время смены темы, сохраняется последняя корректная палитра и чтение повторяется. Если корректной палитры ещё нет, используется встроенная тема по системному режиму, тёмная при отсутствии сигнала. Ручной выбор при временном сбое интеграции не появляется. Вне Omarchy Electron использует обычное поведение Listik.

## Границы интеграции

- Чтение и наблюдение файлов выполняются в основном процессе Electron.
- Изолированный preload предоставляет только версионированный снимок палитры и подписку на её изменения. У сайта нет Node.js, произвольного IPC, доступа к файлам или командам.
- Мост доступен только доверенному документу Listik верхнего уровня. Проверяются адрес и отправитель; внешние страницы не загружаются в привилегированном окне.
- Сайт без моста работает как прежде; новая веб-версия совместима со старым протоколом оболочки.
- Палитра применяется до показа содержимого, насколько позволяет запуск удалённого сайта; загрузочное окно использует тот же фон.

## Дистрибуция и данные

Отдельный каталог оболочки и рецепт Arch PKGBUILD; ярлык и иконка приложения. Веб-сборка не включается в пакет. Публикация в официальный репозиторий Omarchy — отдельная задача, не условие локальной установки.

У Electron собственный постоянный профиль. Подключение к серверу выполняется штатным интерфейсом Listik. Состояние подключения и ошибки синхронизации остаются видимыми.

Офлайн-запуск нужно подтвердить на Electron отдельно: удалённый сайт и собственный профиль не гарантируют его автоматически. Сохраняем существующее кеширование, если оно совместимо с выбранным режимом загрузки; первый запуск без сети показывает понятную ошибку с повтором. Обновления сайта не должны очищать профиль и локальные документы.

## Что остаётся выбрать при реализации

Конкретная версия Electron, средство упаковки, точное сопоставление палитры с CSS-токенами и механизм надёжного наблюдения. Использовать текущий сайт из конфигурации проекта, без произвольного адреса из веб-контента. Эти решения должны быть проверены по документации и текущей установленной версии Omarchy.

Текущий upstream Omarchy использует `colors.toml`, `mode = "light"` и активный каталог `~/.local/state/omarchy/current/theme`. Каталог заменяется при смене темы: наблюдать только открытый файл недостаточно. Для старых версий потребуется проверить фактическую структуру, не предполагать совместимость.

## Проверка результата

- Светлая, тёмная и пользовательская палитры; смена темы при открытом документе.
- Исчезновение и некорректное содержимое файла, повторная замена каталога темы.
- Отсутствие ручного переключения в Omarchy, сохранение переключения в PWA.
- Читаемость текста и состояний во всех проверяемых палитрах.
- Новая установка, подключение к серверу, повторный запуск и офлайн после успешной загрузки.
- Запрет доступа к мосту из внешних страниц и вложенных документов.
- Новая веб-сборка со старой оболочкой; существующие проверки проекта.
