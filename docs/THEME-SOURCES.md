# Theme palette sources

Bundled palette snapshots, reviewed 2026-11-12. These themes change app colors,
not system settings, fonts or document data. Colors are adapted to semantic
roles by `paletteToTokens`; text colors may be adjusted for contrast.

| Catalogue ID | Upstream / variant | License |
| --- | --- | --- |
| listik | Existing Listik CSS, unchanged | Project |
| retro-82, ristretto | [Omarchy themes](https://github.com/omacom/omarchy/tree/quattro/themes), installed colors.toml snapshot | MIT |
| osaka-jade | [Omarchy master colors.toml](https://github.com/omacom/omarchy/blob/master/themes/osaka-jade/colors.toml), classic Osaka Jade | MIT |
| kanagawa | [Kanagawa](https://github.com/rebelot/kanagawa.nvim), Wave / Lotus | MIT |
| dracula | [Classic Dracula specification](https://draculatheme.com/contribute), not Alucard | MIT |
| catppuccin | [Catppuccin](https://github.com/catppuccin/catppuccin), Mocha / Latte | MIT |
| gruvbox | [Gruvbox](https://github.com/morhetz/gruvbox), Dark / Light | MIT/X11 |
| tokyo-night | [Tokyo Night](https://github.com/folke/tokyonight.nvim), Night / Day | Apache-2.0 |
| nord | [Nord](https://github.com/nordtheme/nord), original dark palette | MIT |
| omarchy | Runtime user palette through the desktop bridge | Not bundled |

Redistribution notices are in [public/theme-licenses](../public/theme-licenses/)
and ship unchanged with the web build. Named variants are intentionally limited
to those in the catalogue; unavailable light/dark variants are never invented.
