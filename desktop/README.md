# Listik для Omarchy

Electron с собственным Chromium открывает https://iangor.github.io/Listik/.
Интерфейс получает свежую веб-сборку при следующей загрузке, как PWA;
открытый документ ради обновления не перезагружается. Оболочка и Chromium
обновляются переустановкой новой версии пакета.

## Локальный запуск

Нужны Node.js 22.16+ и npm.

```sh
cd desktop
npm ci
# Если npm не выполнил установочный скрипт Electron:
node node_modules/electron/install.js
npm start
```

У приложения отдельный постоянный профиль Electron. Для существующих данных
откройте меню → Синхронизация → Подключиться к существующему и введите адрес
сервера, код документа и пароль. Содержимое PWA автоматически не переносится.

После первой успешной загрузки работает существующий service worker Listik:
он сохраняет сайт для офлайн-запуска, а IndexedDB — документы. При первом
запуске без сети появляется страница с повтором. Очистка профиля удаляет
локальные данные и офлайн-кеш; для обновления очищать его не нужно.

## Темы

В Omarchy цвета всегда берутся из текущей темы, включая пользовательские.
Переключатель темы и команда её смены скрыты. Изменения применяются без
перезапуска. Шрифты, размеры и расположение элементов остаются как в Listik.
Оттенки текста корректируются для читаемости; исходный цвет фона сохраняется.

Оболочка читает `~/.local/state/omarchy/current/theme/colors.toml`, для старой
структуры — `~/.config/omarchy/current/theme/colors.toml`. Смена каталога и
редактирование файла отслеживаются; при повреждении остаётся последняя
корректная палитра. Вне Omarchy действуют обычные светлая/тёмная темы Listik.

Новая веб-версия должна поддерживать протокол `window.listikDesktop` v1.
Старый сайт без интеграции продолжает открываться в оболочке, но не получает
палитру в интерфейс до публикации веб-доработки.

## Сборка

```sh
npm run package
# Результат: dist/Listik-linux-arm64 или dist/Listik-linux-x64
npm run source
cd packaging
makepkg
# Установка — отдельное действие владельца:
# sudo pacman -U listik-0.1.0-1-aarch64.pkg.tar.*
```

`source` создаёт детерминированный архив исходников рядом с PKGBUILD и
обновляет его SHA-256. Для пересборки нужен доступ к npm и выпускам Electron.
В пакет включены Electron и Chromium; системный Chromium не требуется.
Рецепт поддерживает x86_64 и aarch64, проверка в этой сессии — на aarch64.
Пакет устанавливает `/opt/listik`, команду `listik`, иконку и `.desktop`-файл.
Публикация в официальный репозиторий Omarchy отдельно не выполняется.
У проекта пока нет LICENSE: публичное распространение требует отдельного
решения владельца о лицензии.

## Проверки

```sh
npm test
cd ..
npm run build
node desktop/tests/run-smoke.cjs
```

Smoke-тест использует настоящий Electron с sandbox, временный профиль,
локальные порты 5271/5272, тестовый сервер синхронизации и системный Chromium.
Проверяет первый запуск без сети, повтор, палитру, изоляцию iframe,
получение документа с сервера и перезапуск офлайн. Профиль удаляется после
проверки. Для запуска требуются графическая сессия и зависимости корневого
проекта (`npm ci`). Скриншоты сохраняются в `test-results/omarchy/`.

Не отключайте sandbox для обхода проблем запуска. Диагностика — stdout/stderr
`npm start`; ошибка загрузки не удаляет профиль. Мост предоставляет только
снимок палитры и подписку, только главному документу точного проекта Listik.
