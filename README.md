# Listik

Outliner в стиле Workflowy: один бесконечный bullet-список с мгновенной фильтрацией по `#tag` на документах объёмом «Войны и мира».
Оформление — по образцу Workflowy, в цветах Claude; светлая и тёмная тема переключаются кнопкой в шапке.

Архитектура и план этапов: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```sh
npm install
npm run app        # собрать и запустить приложение: http://127.0.0.1:4173 — установите его
                   # (значок «Установить» в адресной строке Chrome), дальше оно работает без сервера
npm run dev        # dev-сервер; документ хранится в IndexedDB браузера
                   # /?demo — демо, /?sample=200000 — синтетика на 200 тыс. bullet'ов (оба только в памяти)
npm test           # unit-тесты (Vitest)
npm run test:e2e   # e2e в Chromium (Playwright); системный /usr/bin/chromium или CHROMIUM_PATH
npm run typecheck
npm run bench      # бенчмарк на 67 тыс. и 200 тыс. bullet'ов → bench/RESULTS.md
```

Меню «⋯» в шапке: скачать как Markdown или OPML, импорт из файла, автокопия в папку на диске (Chrome, Edge).

Клавиши: Enter — новый bullet / разделить, Tab / Shift+Tab — вложить / вынести, Backspace в начале — склеить с предыдущим, Ctrl+Shift+Backspace — удалить с поддеревом, Alt+Shift+↑/↓ (или Ctrl+Shift+↑/↓) — подвинуть, Ctrl+↑/↓ или стрелка слева — свернуть / развернуть, клик по точке bullet'а или Alt+→ — войти в него (zoom), перетаскивание за точку — переместить (уровень — сдвигом мыши вправо или влево), Alt+← или «хлебные крошки» — выйти, «+» под списком в zoom — новый пункт, клик по «Listik» — на главную со всем свёрнутым, Ctrl+Z / Ctrl+Shift+Z (или Ctrl+Y) — отменить / повторить, Ctrl+F — поиск (слова, «фраза в кавычках», `#тег`; Enter — к первому совпадению), клик по `#тегу` — искать этот тег, Ctrl+Enter — сделано, Ctrl+O — скрыть / показать выполненные, Shift+Enter — заметка под пунктом, Shift+↑/↓ на краю строки или Shift+клик — выделить несколько пунктов (Tab, Delete, Ctrl+C, Ctrl+Enter работают на всём выделенном), Esc — сбросить поиск / выйти из редактирования.
