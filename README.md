# Listik

Outliner в стиле Workflowy: один бесконечный bullet-список с мгновенной фильтрацией по `#tag` на документах объёмом «Войны и мира».
Оформление — по образцу Workflowy, в цветах Claude; в шапке только логотип, поиск и меню «⋯»: светлая и тёмная тема (сама переключается вместе с системной, без неё — тёмная; выбор в меню держится до следующего переключения системы), размер текста (85–150 %, запоминается в браузере), экспорт, импорт и синхронизация — в нём. Над списком — путь от «Главной» до текущего пункта включительно; крошки не сокращаются, длинный путь прокручивается вбок (пальцем, тачпадом, колесом мыши или перетаскиванием мышью) и показывает ближайшие к текущему пункты; заголовок пункта прокручивается вместе со списком, теги и ссылки в нём кликабельны, как в строках. Пока пункт редактируется и клавиатура открыта, над ней стоит панель (на телефоне боком путь над списком на это время прячется, чтобы строке хватило места): четыре группы, разделённые чертой, — место в дереве (вынести, вложить, «Переместить»: вверх, вниз и «Куда…», набор не закрывается, пока двигаете пункт), сам пункт (задача, заметка), то, что трудно набрать на экранной клавиатуре (`#` — тег с подсказкой существующих, `[[]]` — ссылка с подсказкой пунктов), история (отменить, «Ещё»: `(( ))` зеркало, время, жирный, курсив, повторить, удалить пункт со всем вложенным). В заголовке пункта, в который вошли, на панели — заметка, жирный, курсив, время, отменить, повторить. Глубокие ветки на телефоне не сжимаются в столбик: после 4-го уровня каждый следующий сдвигает строку меньше. Стрелки сворачивания на сенсорном экране видны всегда и стоят ровной колонкой в конце строки (точка слева — вход в пункт, стрелка справа — раскрыть). Касание точки ведёт внутрь пункта, удержание (~⅓ с) поднимает его для перетаскивания. Строку можно смахнуть пальцем: влево до конца (дальше ~40 % ширины или быстрым броском) — удалить пункт со всем вложенным (сообщение «Удалено» умеет отменить, удалённое лежит в корзине), вправо — отметить выполненной задачей (у выполненной — снять отметку); отпустите раньше — строка вернётся на место. Свайп не начинается на точке, у самых краёв экрана (там системный жест «Назад») и в строке, которую сейчас правите. Подсказка по жестам — в меню «⋯» → «Жесты и клавиши». Backspace в начале строки на телефоне не склеивает пункты, только удаляет пустой. Пункты связываются ссылками `[[название]]`, а `((название))` делает зеркало: тот же пункт ещё в одном месте, со всем, что у него внутри, — так разные участки дерева собираются в одном месте без лишних вкладок. Все копии равноправны: ромбик стоит у каждой, правка в любой меняет все, а сворачивать и раскрывать пункты в каждой копии можно по-своему. Удаление копии убирает только её; если копия осталась одна, она снова обычный пункт. Поиск и клик по тегу находят и то, что показывает зеркало: внутри пункта, в который вы вошли, найденное под зеркалом видно под ним, даже если сам оригинал лежит в другом месте.

Архитектура и план этапов: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```sh
npm install
npm run app        # собрать и запустить приложение: http://127.0.0.1:4173 — установите его
                   # (значок «Установить» в адресной строке Chrome), дальше оно работает без сервера
npm run dev        # dev-сервер; документ хранится в IndexedDB браузера, каждая правка — сразу
                   # /?demo — демо, /?sample=200000 — синтетика на 200 тыс. bullet'ов (оба только в памяти)
                   # &empty — новый документ без структуры, одна пустая строка (так начинают e2e-тесты)
npm test           # unit-тесты (Vitest)
npm run test:e2e   # e2e в Chromium (Playwright); системный /usr/bin/chromium или CHROMIUM_PATH
npm run typecheck
npm run bench      # бенчмарк на 67 тыс. и 200 тыс. bullet'ов → bench/RESULTS.md
```

Меню «⋯» в шапке: структура с календарём, скачать как Markdown или OPML, импорт из файла, автокопия в папку на диске (Chrome, Edge), синхронизация между устройствами.

## Структура и календарь

Новый документ начинается со структуры в духе PARA. Её же добавляет меню «⋯» → «Создать структуру»: всегда в конец верхнего уровня, уже созданное не трогается. При «Синхронизация → Новый документ на сервере» структура добавляется, если её в документе ещё нет.

- **Inbox**, **Projects**, **Hubs**, **Reference**, **Archive** — папки; что в какую класть, написано в их заметках.
- **`@q1`–`@q4`** — кварталы календаря. В квартале лежат годы, в году — его три месяца, в месяце — недели, в неделе — дни: `@q4` → `@y26` → `@m10` → `@w43` → `@d19 @m10 @y26 @понедельник`. Год везде — короткий тег `@y26` (две последние цифры): поиск `@y26` находит год и дни 2026 года, `@d19 @m10 @y26` — один день, `@d19 @m10` — 19 октября во все годы; ссылка `[[…]]` на день и «Перейти к…» ведут именно в этот год. Дни, созданные раньше без этого тега, получают его сами при следующем запуске, а годы, записанные раньше как `@y2026`, становятся `@y26`. Недели — по ISO, с понедельника. Неделя на стыке месяцев есть в обоих, каждая со своими днями. Годы, месяцы, недели и дни создаются свёрнутыми: раскрытый квартал показывает свои годы, а не все дни года.
- Год появляется целиком, со всеми днями: текущий — вместе со структурой, следующий — при первом попадании в него («Сегодня» 1 января, › из 31 декабря).
- **День при первом входе** любым путём получает шаблон: `#notes` и `todo`, под каждым — пустая строка (без чекбокса; задачей её делает Ctrl+L), затем часы `09:00`, `09:30` … `18:00`. Курсор при входе в день не ставится. Шаблон и год, который создаётся при первом попадании в него, ставит само приложение, поэтому Ctrl+Z их не трогает, а отменяет вашу последнюю правку; ненужное удаляется как обычные пункты.
- **Логотип Listik ведёт в сегодня.** Так же открывается приложение без адреса места (установленное — всегда). Обновление страницы (Ctrl+R, F5, на телефоне — потянуть страницу вниз) в сегодня не ведёт: остаются то же место (и главная тоже), тот же поиск и та же прокрутка. Если приложение стоит открытым в дне, когда наступает полночь, оно само переходит в новый день — сразу, а если вы как раз правите пункт, то когда закончите; свёрнутое или спрятанное за другим окном — при возвращении к нему.
- На главную ведёт «Главная» над списком; на самой главной она сворачивает все пункты верхнего уровня.
- **Дата словом.** `@today`, `@tomorrow`, `@yesterday`, `@monday` … `@sunday` (дни текущей недели, с понедельника по воскресенье, прошедшие тоже), `@lastmonday` … `@lastsunday` (прошлая неделя) и `@nextmonday` … `@nextsunday` (следующая) превращаются в теги дня, как у пункта календаря: «созвон @tomorrow» → «созвон @d22 @m10 @y26 @четверг». Тогда фильтр `@d22 @m10` найдёт и сам день, и эту запись. Слово берётся из подсказки после `@` (Enter, Tab или клик; сразу после `@` предложены сегодня, завтра и вчера, рядом — дата) или заменяется само, когда после него поставлен пробел. Слова английские, потому что `@` есть только в английской раскладке. Дата — по часам устройства в момент вставки; Ctrl+Z возвращает слово. Работает в пункте, заметке и строке записи в Inbox.
- Пока синхронизация после запуска не получила ответа сервера, ни год, ни шаблон дня не создаются: иначе два устройства завели бы по своему.
- Пункты календаря можно переименовывать («@d19 @m10 @понедельник день рождения»), дописывать заметкой и переносить: приложение находит их по тегам и по году, в котором они лежат. День остаётся днём, пока лежит в неделе; запись с тегами дня («созвон @today») в месяце, году или самой неделе днём не считается, и логотип ведёт в настоящий день.
- Фильтр `@d19 @m10` показывает 19 октября всех лет, `@понедельник` — все понедельники, `#notes` — заметки всех дней, `@m10` — октябрь.

## Задачи внутри пункта

Если внутри свёрнутого пункта есть незавершённые задачи, под его текстом видна первая из них (сверху вниз) с коралловым квадратиком и «+N», если их больше. Так видно, что предстоит сделать, не раскрывая пункт. Заметка пункта при этом опускается на строку ниже.

- Квадратик отмечает задачу выполненной — на её месте появляется следующая; Ctrl+Z возвращает.
- Нажатие на текст задачи ведёт к ней: внутрь пункта, где она лежит, курсор — в её конце.
- То же у зеркала (задачи его оригинала) и у пункта со ссылкой `[[…]]` (задачи того, куда ведёт ссылка, или он сам, если это задача). У раскрытого пункта подсказки нет: задачи и так видны в списке.

## Шаблоны

Шаблон — любой пункт с тегом `#template` вместе со всем, что в нём; название шаблона — текст пункта без тега.

- В любом пункте наберите `/template` (или `/` и пару букв названия) — подсказка покажет шаблоны; выберите нужный.
- Вставляется то, что внутри шаблона, — без его заголовка с `#template` и на уровне пункта, где набрали команду: если пункт пустой, первый пункт шаблона встаёт на его место, остальные следом; если в нём уже есть текст — всё встаёт после него. Курсор — в конце первого вставленного.
- Копируется всё: текст, заметки, задачи (отметки сняты), вложенные пункты. Сам шаблон не меняется. Ctrl+Z отменяет вставку целиком. В пустом шаблоне вставлять нечего — об этом скажет сообщение.

## Быстрая запись в Inbox

Мысль посреди работы — сразу в Inbox (он находится по первому слову названия, эмодзи и оформление вокруг не мешают: «📥 **Inbox**» подходит), не уходя с места: Ctrl+Shift+Space (работает и во время правки пункта) или значок лотка в шапке; на телефоне и планшете — первый пункт меню «⋯» «Записать в Inbox».

- Появляется одна строка (на компьютере под шапкой, на телефоне снизу над клавиатурой); список не сдвигается и не затемняется. Теги, `[[ссылки]]`, `/time` и даты словом (`@tomorrow` и пробел) работают как в пункте.
- Enter записывает в конец Inbox (его нет — он появится в конце списка) и закрывает строку; курсор возвращается туда, где был. В сообщении внизу «Записано в Inbox · Отменить» слово «Inbox» ведёт к только что записанному — курсор в его конце, чтобы сразу дописать.
- Esc закрывает строку, набранное ждёт до следующего раза.

## Корзина

Меню «⋯» → «Корзина» открывает панель справа от списка (на телефоне — снизу). Она не мешает работе: курсор остаётся в списке, панель — открытой, пока её не закроете ×, в том числе после перезагрузки (на телефоне приложение всегда открывается без корзины: там она занимает полэкрана).

- В панели — недавно удалённые пункты по дням, новые сверху: текст, время, сколько в пункте вложенных и откуда он удалён. Пустые строки, стёртые Backspace, сюда не попадают, а пункт, у которого сначала стёрли текст, а потом удалили его самого, попадает вместе с этим текстом.
- «Вернуть» ставит пункт со всем вложенным на прежнее место, между теми же соседями, и переводит курсор в него. Если прежнего места уже нет (его тоже удалили), пункт встаёт в конец списка. Ctrl+Z отменяет возврат.
- Поле «Найти в удалённом» сужает список; на телефоне панель остаётся над клавиатурой, пока печатаете в нём (при правке пункта она уступает место клавиатуре). Удалённое хранится 30 дней.

## Синхронизация между устройствами

Один документ на ноутбуке, телефоне и планшете, работа без сети, слияние правок. Данные шифруются на устройстве: сервер хранит только шифротекст и не знает ни пароля, ни ключа.

1. Поднимите сервер по инструкции [server/DEPLOY.md](server/DEPLOY.md) (Node 20+, без зависимостей) или попросите об этом администратора.
2. На первом устройстве: меню «⋯» → «Синхронизация между устройствами…» → «Новый документ на сервере»: адрес сервера и пароль (от 8 знаков). Текущий документ шифруется и становится общим. В диалоге появится **код документа**.
3. На каждом следующем устройстве: тот же пункт меню → «Подключиться к существующему»: адрес сервера, код документа, пароль. Документ в этом браузере заменяется общим.
4. Состояние синхронизации написано в меню «⋯» и в подсказке его кнопки. Пока правки ждут отправки, нет связи (правки накапливаются и уйдут позже) или случилась ошибка, на кнопке «⋯» горит коралловая точка.

Пароль запоминается на устройстве; «Забыть пароль здесь» в диалоге заставит спросить его при следующем открытии. Забытый пароль восстановить нельзя. Свёрнутость пунктов — своя на каждом устройстве.

Пока на сервере стоит `LISTIK_ALLOW_CREATE=1`, любой, кто знает его адрес, может завести там **свой** документ (ваш он не увидит и не угадает). После создания своего документа поставьте `0`: сервер будет обслуживать только существующие документы, а подключать к ним новые устройства по-прежнему можно.

Приложение публикуется на GitHub Pages ([docs/DEPLOY.md](docs/DEPLOY.md)); сервер данных — отдельно, на своём хостинге.

Все клавиши — в приложении: `?` или Ctrl+/.

Клавиши: Enter — новый bullet / разделить, Tab / Shift+Tab — вложить / вынести, Backspace в начале — склеить с предыдущим (пустой первый пункт под заголовком — удалить, курсор в конец заголовка), Ctrl+Shift+Backspace — удалить с поддеревом, Alt+Shift+↑/↓ (или Ctrl+Shift+↑/↓) — подвинуть, Ctrl+↑/↓ или стрелка слева — свернуть / развернуть, клик по вертикальной линии — свернуть пункт, от которого она идёт (линия подсвечивается под указателем), клик по последней крошке (где вы сейчас; на главной — «Главная») — свернуть весь первый уровень, ещё раз — развернуть, клик по точке bullet'а или Alt+→ — войти в него (zoom), перетаскивание за точку — переместить (уровень — сдвигом мыши вправо или влево), Alt+← или «хлебные крошки» — выйти, «+» под списком (на главной и в zoom) — новый пункт, клик по «Listik» — на главную со всем свёрнутым, Ctrl+Z / Ctrl+Shift+Z (или Ctrl+Y) — отменить / повторить, Ctrl+K (или «Перейти к пункту…» в меню «⋯»; только на компьютере) — строка «Перейти к…» посреди экрана: наберите название пункта — под строкой места с путём к ним (одноимённые — все, каждое со своим путём; выше то, что правили последним), первое уже выбрано, Enter входит в него и ставит курсор на первый пункт (↑/↓ — другое место, клик — войти без правки, Esc или клик мимо — закрыть, курсор вернётся на место); в пустой строке — недавние места; `today` или `сегодня` (хватит первых трёх букв) ставит первым «Сегодня» — Enter ведёт в сегодняшний день, как клик по логотипу; поиск и дерево при этом не меняются; Ctrl+Shift+M (на телефоне — «Переместить» → «Куда…» на панели правки) — переместить пункт или выделенные в другое место по названию: та же строка спрашивает «Переместить … в…» (на телефоне — вверху экрана), до набора предлагает, куда переносили недавно, Enter кладёт пункты последними в выбранное место, курсор остаётся на следующем пункте, сообщение ведёт туда и умеет отменить, Esc — ничего не переносить; Ctrl+F — поиск (слова, «фраза в кавычках», `#тег` — по началу, как слово: `#n` находит `#next` и `#note`, `-исключить`, `OR`, `is:todo` / `is:done` / `is:task`; Enter — к первому совпадению; справа — сколько пунктов найдено, если ничего не нашлось, вместо счётчика над списком написано «Ничего не найдено»; на телефоне счётчик — одно число; звёздочка в поле сохраняет поиск в избранное, при фокусе на поле избранные поиски выпадают списком; переход в найденный пункт по точке сбрасывает поиск, и пункт виден целиком; переход вверх по крошкам поиск сохраняет, и его результаты видны на каждом уровне; если найден сам пункт, в который вошли, под ним видно всё вложенное), клик по `#тегу` или `@тегу` — искать этот тег (`@теги` — второй набор, работает так же, `#иван` и `@иван` — разные теги), Ctrl+L (⌘L на Mac; на телефоне — кнопка задачи на панели правки) — по кругу три состояния: сделать задачей (чекбокс), отметить выполненной, снова обычный пункт; клик по чекбоксу только отмечает и снимает отметку, Ctrl+Shift+L — снова обычный пункт, выполненные задачи остаются на месте зачёркнутыми, Ctrl+B / Ctrl+I — жирный / курсив (в тексте это `**жирное**` и `*курсив*`, вне правки маркеры скрыты; клик у края оформленного текста ставит курсор за маркерами, так что Enter его не разрывает), `/time` — вставить текущее время (ЧЧ:ММ), `/` и `#` — подсказка по командам и существующим тегам (↑/↓ и Enter или касание — выбрать, дописывать не обязательно), веб-адреса (`https://…`, `www.…`) в тексте и заметках подчёркнуты со стрелкой ↗ и открываются в браузере по клику; выделите слова и вставьте поверх них адрес — слова станут ссылкой, в тексте это Markdown `[слова](https://…)`, вне правки видны только слова, `[[` — ссылка на другой пункт: скобки закрываются сами, подсказка ищет пункты по названию, клик по ссылке ведёт внутрь этого пункта, туда, где он лежит в документе (ссылка хранит название; если переименовать пункт, ссылки на него сами получат новое название, когда курсор уйдёт из пункта, — сообщение скажет, в скольких пунктах, Ctrl+Z вернёт прежние); если такого пункта ещё нет, клик по ссылке создаёт его последним в Inbox структуры и открывает (пока ссылку только пишут, ничего не создаётся), под пунктом, на который ссылаются, — плашки «Ссылки сюда» с местами, откуда на него ссылаются (место, откуда вы пришли, — первым, со стрелкой «←»): касание ведёт туда, каретка встаёт за ссылкой, `((` — зеркало пункта: выберите пункт в подсказке, и эта строка станет его копией (ромбик вместо точки у обеих); если такого пункта ещё нет, выберите «Создать «название» в Inbox» или допечатайте `))` — пункт появится последним в Inbox, а строка станет его копией (допечатанные `))` с названием существующего пункта тоже делают копию): текст, заметка, задача и вложенные пункты у копий общие — правка в любой меняет все; Backspace в начале копии, Ctrl+Shift+Backspace или удаление выделения убирают только эту копию (последняя оставшаяся снова обычный пункт); сворачивание у каждой копии своё, и пункты внутри одной копии раскрываются и сворачиваются, не трогая другие (запоминается на устройстве); точка копии ведёт туда, где пункт лежит в документе, Shift+Enter — заметка под пунктом (вне правки видны её первые 3 строки, при правке пункта — вся; у пункта, в который вошли, заметка видна целиком под заголовком, Shift+Enter в заголовке — к ней), Shift+↑/↓ на краю строки или Shift+клик — выделить несколько пунктов (Tab, Delete, Ctrl+C, Ctrl+L работают на всём выделенном), Esc — сбросить поиск / выйти из редактирования.
