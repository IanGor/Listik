# Listik

Outliner в стиле Workflowy: один бесконечный bullet-список с мгновенной фильтрацией по `#tag` на документах объёмом «Войны и мира».
Оформление — по образцу Workflowy, в цветах Claude; светлая и тёмная тема переключаются кнопкой в шапке. На телефоне шапка короче: переключатель темы и облако синхронизации переезжают в меню «⋯». Пока пункт редактируется, над клавиатурой стоит панель: вынести, вложить, вверх, вниз, задача, заметка, отменить, повторить и «Готово».

Архитектура и план этапов: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```sh
npm install
npm run app        # собрать и запустить приложение: http://127.0.0.1:4173 — установите его
                   # (значок «Установить» в адресной строке Chrome), дальше оно работает без сервера
npm run dev        # dev-сервер; документ хранится в IndexedDB браузера
                   # /?demo — демо, /?sample=200000 — синтетика на 200 тыс. bullet'ов (оба только в памяти)
npm test           # unit-тесты (Vitest)
npm run test:e2e   # e2e в Chromium (Playwright); системный /usr/bin/chromium или CHROMIUM_PATH
npm run typecheck
npm run bench      # бенчмарк на 67 тыс. и 200 тыс. bullet'ов → bench/RESULTS.md
```

Меню «⋯» в шапке: скачать как Markdown или OPML, импорт из файла, автокопия в папку на диске (Chrome, Edge), синхронизация между устройствами.

## Синхронизация между устройствами

Один документ на ноутбуке, телефоне и планшете, работа без сети, слияние правок. Данные шифруются на устройстве: сервер хранит только шифротекст и не знает ни пароля, ни ключа.

1. Поднимите сервер по инструкции [server/DEPLOY.md](server/DEPLOY.md) (Node 20+, без зависимостей) или попросите об этом администратора.
2. На первом устройстве: меню «⋯» → «Синхронизация между устройствами…» → «Новый документ на сервере»: адрес сервера и пароль (от 8 знаков). Текущий документ шифруется и становится общим. В диалоге появится **код документа**.
3. На каждом следующем устройстве: тот же пункт меню → «Подключиться к существующему»: адрес сервера, код документа, пароль. Документ в этом браузере заменяется общим.
4. Облако в шапке показывает состояние: точка — изменения ещё отправляются, перечёркнуто — нет связи (правки накапливаются и уйдут позже), восклицательный знак — ошибка (подробности в меню). На телефоне облака в шапке нет: состояние написано в меню «⋯», а пока правки ждут отправки или нет связи, на его кнопке горит точка.

Пароль запоминается на устройстве; «Забыть пароль здесь» в диалоге заставит спросить его при следующем открытии. Забытый пароль восстановить нельзя. Свёрнутость пунктов — своя на каждом устройстве.

Пока на сервере стоит `LISTIK_ALLOW_CREATE=1`, любой, кто знает его адрес, может завести там **свой** документ (ваш он не увидит и не угадает). После создания своего документа поставьте `0`: сервер будет обслуживать только существующие документы, а подключать к ним новые устройства по-прежнему можно.

Приложение публикуется на GitHub Pages ([docs/DEPLOY.md](docs/DEPLOY.md)); сервер данных — отдельно, на своём хостинге.

Все клавиши — в приложении: `?` или Ctrl+/.

Клавиши: Enter — новый bullet / разделить, Tab / Shift+Tab — вложить / вынести, Backspace в начале — склеить с предыдущим, Ctrl+Shift+Backspace — удалить с поддеревом, Alt+Shift+↑/↓ (или Ctrl+Shift+↑/↓) — подвинуть, Ctrl+↑/↓ или стрелка слева — свернуть / развернуть, клик по точке bullet'а или Alt+→ — войти в него (zoom), перетаскивание за точку — переместить (уровень — сдвигом мыши вправо или влево), Alt+← или «хлебные крошки» — выйти, «+» под списком в zoom — новый пункт, клик по «Listik» — на главную со всем свёрнутым, Ctrl+Z / Ctrl+Shift+Z (или Ctrl+Y) — отменить / повторить, Ctrl+F — поиск (слова, «фраза в кавычках», `#тег`, `-исключить`, `OR`, `is:todo` / `is:done` / `is:task`; Enter — к первому совпадению), клик по `#тегу` — искать этот тег, Ctrl+Enter — сделать задачей (чекбокс), затем отметить выполненной (или клик по чекбоксу), Ctrl+Shift+Enter — снова обычный пункт, Ctrl+O — скрыть / показать выполненные задачи, Shift+Enter — заметка под пунктом, Shift+↑/↓ на краю строки или Shift+клик — выделить несколько пунктов (Tab, Delete, Ctrl+C, Ctrl+Enter работают на всём выделенном), Esc — сбросить поиск / выйти из редактирования.
